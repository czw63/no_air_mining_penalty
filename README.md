# 去除mc的浮空挖掘惩罚

## 字面意思，脚不着地的时候的挖掘速度的惩罚去除

个人小服务器里使用的，得服务器客户端双端都装才会起作用
（我是配合[客户端飞行](https://github.com/ReallyChooseC/Client-Flight-Mod)用的）

## 支持版本

| 加载器 | 版本 |
| --- | --- |
| Fabric | 26.3（Loader ≥ 0.20.1，Java 25） |
| NeoForge | 26.3（NeoForge ≥ 26.3.0.101，Java 25） |

旧版本（1.21.1 ~ 1.21.11）请用 v1.0.x 的 jar。

26.3 起水下挖掘惩罚改成了 `SUBMERGED_MINING_SPEED` 属性，本 mod 只处理空中惩罚，水下惩罚保持原版。
